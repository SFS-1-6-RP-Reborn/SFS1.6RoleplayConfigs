# SFS 1.6 Roleplay Configs
The configs of the SFS 1.6 roleplay.

## JSON Formatting
All launches must follow the format shown below

```json
{
  "event": "What happened in the launch?",
  "who": "Who did the launch?"
}
```
  
All space agencies must follow the format below
```json
{
  "name": "What's the space agencies name?",
  "owner": "Who owns the space agency?",
  "type": "Is it private or goverment owned?",
  "money": "How much money they have",
  "status": "What is their status?",
  "comms": "What is their comms teir>"
},
```

All relations must follow the format below
```json
{
    "name": "What's the relations name?",
    "what": "What is the relation about?",
    "who": "Who is involved in the relation?"
}
```

## ICSA
The Interplanetary Coordination & Standards Authority (ICSA) is a organization that defines new zones and standards, not a actual agency.

**Orbit Zones**
* Low earth orbit: 30-140km
* Mid earth orbit: 140-300km
* High earth orbit: 300-earth SOIkm
* GEO: 1000km
